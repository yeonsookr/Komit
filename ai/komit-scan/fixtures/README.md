# 검사 시험용 프로젝트

`komit-scan` 이 문제를 제대로 찾는지 재기 위해 만든 **시험용 코드**다.

## ⚠ 실제로 쓰지 말 것

`soap-shop/` 안의 코드에는 **일부러 심어 놓은 결함**이 들어 있다. 인증 누락, 결제 금액 변조, 비밀번호 평문 저장 같은 것들이 의도적으로 들어 있다.

- 배포하지 않는다
- 다른 프로젝트에 복사하지 않는다
- 코드 품질 검사 대상에서 제외한다
- 의존성을 설치하거나 실행하지 않는다. 읽히기만 하면 된다

바이브코딩으로 만든 서비스가 실제로 어떤 모습인지를 흉내 낸 것이다.

## 쓰는 법

1. `soap-shop/` 을 대상으로 검사를 돌린다
2. 나온 결과를 `soap-shop/EXPECTED.md` 와 맞춰 본다
3. 못 찾은 것, 없는데 찾았다고 한 것을 센다

## 무엇을 재는가

| 재는 것 | 뜻 |
| --- | --- |
| 찾은 비율 | 심어 둔 결함 중 몇 개를 찾았나 |
| 헛것 | 심지 않은 것을 문제라고 했나 |
| 분류 정확도 | 분류를 제대로 넣었나 |
| 심각도 정확도 | 심각도가 맞나 |
| 점수 | 계산이 정답과 같은가 |
| 물어볼 것 | 만들어야 할 문항을 만들었나 |

**헛것이 가장 중요하다.** 없는 문제를 만들어내면 의뢰인이 필요 없는 일을 개발자에게 맡기게 된다.

## 띄워 보기

이 시험판은 실제로 돈다. 바이브코딩으로 만든 서비스가 그렇듯 **동작하는 것과 뚫린 것이 섞여 있어야** 헛것을 잴 수 있기 때문이다.

```bash
cd ai/komit-scan/fixtures/soap-shop
npm install
npm run dev
```

로그인은 `mimi@example.com` / `test`, 운영자는 `admin@example.com` / `12345` 다. 시험용으로만 쓰는 값이다.

띄운 상태에서 로그인 없이 `/api/admin/users` 로 들어가면 회원 정보가 그대로 나온다. 심어 둔 결함이 실제로 뚫리는 것을 눈으로 볼 수 있다.

**로컬에서만 띄운다.** 밖으로 열지 않는다.
