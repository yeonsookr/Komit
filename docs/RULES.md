# Komit 규칙서 (`RULES.md`)

Komit의 **정책 값과 불변식**을 모아 놓은 단일 출처다.

| 항목 | 내용 |
| --- | --- |
| 목적 | 화면·API 명세·코드에 흩어진 규칙을 한곳에서 관리한다 |
| 기준일 | 2026-09-15 |
| 관계 문서 | 기획서 `proposal.md`, 백엔드 `BACKEND_CONVENTIONS.md`, 프론트 `FRONTEND_CONVENTIONS.md` |

## 이 문서를 쓰는 법

- **숫자와 기한은 이 문서에만 둔다.** 기획서·API 명세·화면 문구는 값을 다시 적지 않고 규칙 번호를 인용한다.
- 규칙 번호는 바뀌지 않는다. 규칙이 사라지면 번호를 비워 두고 재사용하지 않는다.
- 값을 바꿀 때는 **영향 범위** 열에 적힌 곳을 모두 함께 고친다.
- 근거가 없는 규칙은 넣지 않는다. 정하지 못한 것은 맨 아래 「미확정」에 둔다.

## 4. 계약

| 번호 | 규칙 | 값 | 영향 범위 |
| --- | --- | --- | --- |
| `R-CON-01` | 의뢰인과 개발자가 모두 서명하기 전에는 계약이 성립하지 않는다. | 양측 서명 | API, 화면 |
| `R-CON-02` | **서명한 계약서는 수정할 수 없다.** 이후 변경은 계약서를 다시 써서 양측이 다시 서명한다. (`R-CON-03`) | 불가역 | API, 화면 |
| `R-CON-03` | 금액·기간·확인 문장이 바뀌면 개발자가 계약서를 다시 보내고 양측이 각각 승인한다. | — | API, 화면 |
| `R-CON-04` | 개발계약의 금액은 전체 작업 기준으로 합의한다. 작업별 금액은 배분 표시다. | — | API, 화면 |
| `R-CON-05` | 계약 양식은 판으로 관리한다. 본문을 고치면 새 판이 만들어지고 이전 판은 보관된다. | `v3`, `v4` … | 운영 콘솔, API |
| `R-CON-06` | 계약 양식의 자리표시자는 `{{ }}` 로 적고 계약 데이터로 채운다. | `{{client_name}}` 등 | 운영 콘솔 |
| `R-CON-07` | 컨설팅도 계약서를 작성하고 결제한다. 상담과 달리 유료다. | — | API, 화면 |

## 기간 값 모음

바꿀 일이 잦은 값만 따로 모았다. 고칠 때는 해당 규칙의 영향 범위를 함께 본다.

| 값 | 규칙 | 현재 |
| --- | --- | --- |
| 작업 확인 자동 통과 | `R-QA-02` | 3일 |
| 지급 소요 | `R-PAY-02` | 3영업일 |
| 신고 가능 무응답 기간 | `R-RPT-01` | 3일 |
| 계좌 1원 인증 유효 시간 | `R-ACC-02` | 10분 |
| 탈퇴 데이터 보관 | `R-ACC-06` | 30일 |
| 프로필 노출 포트폴리오 | `R-DEV-02` | 3건 |

`R-QA-02`와 `R-RPT-01`은 값이 같지만 서로 다른 규칙이다. 한쪽을 바꿔도 다른 쪽이 따라가지 않는다.

## 미확정

| 항목 | 상태 |
| --- | --- |
| 중개 수수료 요율 | 정하지 않음 (`R-PAY-07`) |
| 검사 지시문 배포 방식의 프로젝트 번호 처리 | 프로젝트별 발급으로 가정 중 (`R-SCAN-03`). 확정 필요 |
| 컨설팅 대금의 에스크로 경유 여부 | 개발계약은 예치를 거치나 컨설팅은 즉시 결제로 보임. 확정 필요 |
| 지급 소요 단축 | 3영업일 → 2영업일 공지가 화면에 있으나 적용 시점 미정 (`R-PAY-02`) |
| 갈래 선택 후 상담방 잠금 | MVP 범위에서 제외 (`R-MATCH-03`) |
| 리프레시 토큰 만료 기간 | 미정 (`docs/jwt-samples.md`). 정해지기 전까지 FE 는 리프레시 쿠키를 브라우저를 닫으면 사라지는 세션 쿠키로 둔다 |
| 계약 특약·추가 예치 | 현재 범위에서 제외. `escrows.expected_amount`는 생성 후 불변이며 증액 흐름을 두지 않는다. 나중에 되살릴 수 있어 목의 `addDeposit`을 지운 이력을 남긴다 (`R-CON-04`) |
| 계좌 1원 인증 실패 임계 횟수 | 미정. `R-ACC-03`은 "반복해서 틀리면 취소"만 정하고 횟수는 없다. `account_verifications.attempt_count` 임계값 확정 필요 |
