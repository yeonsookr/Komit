# 데모용 예시 프로젝트

Komit이 무엇을 하는지 보여주기 위한 **가상의 의뢰인 프로젝트**다.

바이브코딩으로 서비스를 만든 사람이 Komit에 찾아왔다고 치고, 그 사람의 코드를 여기 둔다.

```
demo/
└─ <프로젝트 이름>/    의뢰인이 만들었다고 치는 앱
```

| 프로젝트 | 무엇 | 스택 | 포트 | 정답표 |
| --- | --- | --- | --- | --- |
| [`soap-shop`](soap-shop/) | 수제 비누를 파는 작은 쇼핑몰 | Next.js · 파일 저장 | 3000 | [보기](../ai/komit-scan/fixtures/soap-shop/EXPECTED.md) |

프로젝트를 새로 더하는 법은 [`ai/komit-scan/fixtures/README.md`](../ai/komit-scan/fixtures/README.md) 에 있다. 앱은 여기에 두고, 정답표는 그쪽에 둔다.

---

## ⚠ 일부러 뚫어 둔 코드다

`soap-shop` 에는 **결함이 의도적으로 심어져 있다.** 로그인 없이 회원 정보가 열리고, 결제 금액을 바꿔 보낼 수 있다.

- 배포하지 않는다
- 다른 프로젝트에 복사하지 않는다
- 코드 품질 검사 대상에서 제외한다
- **로컬에서만 띄운다.** 밖으로 열지 않는다

실제 바이브코딩 서비스가 어떤 모습인지를 흉내 낸 것이다. **돌아가는 코드와 뚫린 코드가 섞여 있어야** 검사가 제 일을 하는지 알 수 있다.

## 띄우기

```bash
cd demo/<프로젝트 이름>
npm install
npm run dev
```

프로젝트마다 포트가 다르다. 위 표를 본다. `soap-shop` 은 `http://localhost:3000` 이다.

`.claude/launch.json` 에 등록해 두면 Claude Code 에서 바로 띄울 수 있다. 프로젝트를 더하면 거기에도 한 줄 더한다.

시험용으로만 쓰는 값이다.

## 데모에서 쓰는 법

### 1. 잘 돌아가는 것을 먼저 보인다

상품을 고르고, 로그인하고, 주문까지 해 본다. 겉으로는 멀쩡한 쇼핑몰이다.

### 2. 뚫린 것을 보인다

로그인하지 않은 채로 아래 주소에 들어간다.

```
http://localhost:3000/api/admin/users
```

**회원 전체의 이름·이메일·휴대폰 번호·비밀번호가 그대로 나온다.**

> 돌아가는 것과 안전한 것은 다릅니다. 만든 사람은 이걸 모릅니다.

### 3. 검사한다

Komit 검사 파일이 이미 프로젝트에 들어 있다 (`komit-scan.md`). Claude Code 에서 검사를 요청하면 `komit-result.md` 가 만들어진다.

### 4. 결과를 올린다

Komit 화면에서 그 파일을 올리면, 방금 본 그 구멍이 진단서에 그대로 나온다.
