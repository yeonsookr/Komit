# AGENTS.md — mock

FE 개발용 목 서버. 이 디렉터리에서 작업하는 에이전트는 아래 세 가지를 반드시 지킨다.
**이 프로젝트는 개인 프로젝트가 아니라 정해진 구조와 컨벤션을 지켜야 하는 팀 프로젝트다.**

---

## 1. 데이터의 출처는 ERD다

ERD는 **ERD Cloud MCP**로 조회한다. 참고 주소:

- [서비스 ERD](https://www.erdcloud.com/d/8MwYuDGzhN9ZwCqyi)
- [에스크로 ERD](https://www.erdcloud.com/d/DCGEGoSqXrYyEj9hr)

### 절대 규칙

- **ERD Cloud에 정의되지 않은 데이터는 API 응답에 넣을 수 없다.** 있으면 편할 것 같은 필드,
  FE가 요청한 것 같은 필드, 다른 API에 있으니 여기도 있겠거니 하는 필드 — 전부 금지다.
  응답에 필요한데 ERD에 없으면 임의로 만들지 말고 **작업을 멈추고 ERD 담당자에게 확인한다.**
- **속성 네이밍은 수정할 수 없다.** ERD의 속성명을 그대로 쓴다. 더 명확한 이름이 떠올라도
  바꾸지 않는다. 바꿔야 한다면 ERD를 먼저 고친다.
- **바꿀 수 있는 건 표기 컨벤션뿐이다.** `snake_case` ↔ `camelCase` 같은 표기 변환은 허용되고,
  단어 자체를 바꾸거나 빼거나 더하는 것은 허용되지 않는다.
  (예: ERD `created_at` → 응답 `createdAt` ○ / 응답 `createdDate` ✗)

### 혼동이 우려되는 필드는 문서에 못 박는다

`id`처럼 어느 테이블의 것인지 헷갈릴 수 있는 필드는 **docs의 description에 무엇의 id인지
분명하게 적는다.** 한 응답 안에 여러 `id`가 섞여 있으면 각각이 무엇을 가리키는지 다 적는다.

## 2. 공통 응답 형식과 상태코드를 지킨다

- 프로젝트에 정해진 **default API 응답 형식**을 따른다. 이 엔드포인트만 편하게 다른 모양으로
  내보내지 않는다.
- **상태코드도 정해진 규칙을 따른다.** 성공은 성공대로, 실패는 실패대로 프로젝트가 약속한
  코드를 쓴다. 전부 200으로 뭉개지 않는다.
- 형식이나 코드를 바꿔야 할 이유가 생기면 목 서버에서 임의로 바꾸지 말고 **팀 합의를 먼저 거친다.**
  목 서버가 먼저 어긋나면 FE가 그 어긋난 모양에 맞춰 화면을 짜고, 실제 BE가 붙을 때 다시 뜯게 된다.

규약의 기준은 **`app/routers/default.py`의 default API**다. 응답 형식·상태코드·description
작성 방식을 이 API에 맞춘다. 규약이 바뀌면 default API를 먼저 고치고 나머지를 따라 맞춘다.

## 3. docs는 API 명세 페이지다

이 목 서버의 **docs(Swagger) 페이지를 팀의 API 명세서로 쓴다.** 그러므로 `description`은
개발자가 개발 중에 기준으로 삼을 수 있는 정보여야 한다.

### description에 들어가야 하는 것

1. **API 소개** — 이 API가 무엇을 하는 것인지
2. **케이스 소개** — **어떤 응답이 어떤 상황에 발생하는지**

즉 "이 응답은 이럴 때 나온다"를 적는다.

### description에 들어가면 안 되는 것

- **구현을 어떻게 해야 하는지.** 내부 로직, 처리 순서, 어떤 테이블을 조회하는지 따위는
  명세를 읽는 사람에게 필요 없다.

### 예

```
○  요청서 상세 조회.
   - 200: 요청서가 존재하고 조회 권한이 있을 때
   - 403: 해당 요청서의 의뢰인·개발자가 아닌 사용자가 조회했을 때
   - 404: 요청서가 삭제되었거나 존재하지 않는 id일 때

✗  requestId로 requests 테이블을 조회한 뒤 권한을 검사해 응답한다
```

## 이 목 서버 자체의 성격

- **DB 연결 없음 · 비즈니스 로직 없음.** 응답은 하드코딩한다.
- 상태를 저장하지 않는다. 호출 순서에 따라 응답이 달라지면 안 된다.
- 라우터는 명세 영역 단위로 쪼개고 `app/routers/__init__.py`의 `ROUTERS`에 등록한다.
