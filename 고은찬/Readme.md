### 📅 2026-08-27 (목)

**오늘 한 것**
- **전문가 리뷰 1차 세션 참가** (우리은행 현직 개발자) — 사전 질문지 기반 프로젝트 소개·팀 소개 장표 제작 및 발표 (`expert_review_intro.html`, 8장)
- **코밋 인프라 구조도(설계) 작성** — K3s 클러스터에 에스크로 서버·DB(Active/Standby)를 코밋 서버와 분리 구성, 장표 7페이지에 반영
- 장표 기능 정의를 **기획 v5와 교차 검증** — 사전 질문지에 빠져 있던 ① 출시 패스(AI 소스 검사 → 스스로 출시)를 주요 기능·플로우에 반영
- **"정성적 갈등 → 정량적 전환" 레퍼런스 리서치** — "레퍼런스 없다"는 피드백 대응. eBay ODR은 물품·비AI라 반례로 판정하고, AAA AI Arbitrator(2025.11, 건설 용역 LLM 중재)·건설 변경지시서/기성고 제도·GenAI 사실정리 도구(Relativity aiR 등)·국내 조정기구 통계로 3층 근거 구성
- **컨설턴트 미팅 피드백 정리 및 설득 논리 초안 작성** — "정량적 지급 조건 = 확인 문장(이진 판정)", "AI 판정 3단 플로우(룰 자동집행 → AI 사실 정리 → 외부 조정)" 등. ⚠ 정성적 갈등의 정량적 전환 방안은 아직 팀 합의 전 — **팀원들과 회의 필요**
- **설문조사 배포 및 수집중**

**배운 것 / 정리**
- 정성적 갈등("말했다/안 했다")은 판정으로 푸는 게 아니라 **계약 시점 구조화로 예방**하는 것 — 건설업이 변경지시서로 100년 강제해온 원리와 동형
- 콘텐츠분쟁조정위 접수 17,202건 중 조정 진입 34% — 대부분 **기록 부재**로 실패. "판정 가능한 기록을 미리 만드는 것"이 서비스의 존재 이유
- 용역 분쟁의 AI 처리는 이미 시작됨: AAA-ICDR AI Arbitrator (2025.11, 문서 기반 건설 분쟁, 시간 20~25%·비용 35% 절감) — 단 판정은 항상 인간이 확정
