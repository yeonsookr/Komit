## 1. 기획 개요

> 기획이 바뀌면 이 섹션을 덮어쓰고, 무엇이 왜 바뀌었는지는 아래 일자별 기록에 남깁니다.

### 문제 정의
바이브 코딩으로 앱을 만든 비개발자는 배포·DB 연결·도메인 단계에서 막혀 개발자를 찾지만, **무엇을 어디까지 하기로 했는지, 언제 대금을 줘야 하는지**가 정해지지 않아 거래가 성사되지 않거나 분쟁으로 끝납니다. 의뢰인은 요청서를 못 쓰고 결과물을 판단하지 못한 채 선불이 불안하고, 개발자는 범위 밖 작업이 밀려들고 승인이 미뤄지면 대금을 못 받습니다.

코밋은 이 합의를 상담 단계에서 문장으로 못 박고, 그 문장을 그대로 대금 지급 조건으로 씁니다.

### 주요 기능
1. 바이브코더 ↔ 개발자 1:1 연결 (무료 상담 → 컨설팅 / 개발)
2. 상담 채팅 AI 요약 → 개발자 검수 → 요청서 자동 생성
3. 확인 문장 기반 조건부 분할 지급 (통과한 작업만 예치금에서 출금)
4. 예치금 원장 · 정산 · 분쟁 조정
